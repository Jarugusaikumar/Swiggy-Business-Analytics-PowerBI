# Raw Data

This folder contains the raw synthetic data used for the Swiggy Business & Operations Analytics project.

The dataset is based on the original public educational project by Harsh Belekar and adapted for a portfolio-style analysis workflow. The data is synthetic and intended for learning, analysis, and dashboard prototyping.

Files:
- users.csv
- restaurants.csv
- menu.csv
- orders.csv
- order_items.csv

Data profile:
- 10,000 users
- 1,000 restaurants
- 15,658 menu items
- 600,000 orders
- 1,667,399 order items

These files are the starting point for SQL ingestion, data quality checks, Python EDA, and Power BI modeling.
