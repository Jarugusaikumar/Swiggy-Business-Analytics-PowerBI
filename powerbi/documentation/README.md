# Power BI documentation

This folder documents how to work with the report included in this project.

## Included assets
- `../Swiggy_Business_Analytics.pbix` – report file copied from the original dashboard for portfolio use
- `../screenshots/` – screenshot previews that can be displayed in GitHub or a portfolio site
- `report_pages.md` – proposed page breakdown
- `dax_measures.md` – recommended cleaned-up DAX measures

## How to view the report
1. Open the `.pbix` file in Power BI Desktop.
2. If the file is too large for GitHub tracking, use Git LFS as configured in `.gitattributes`.
3. Refresh the model after connecting to the source tables or processed data files.
